Metric definitions and data quality

Pipeline: seeded event CSV → dbt staging → ordered session fact → independent-subject and segment marts → statistical report. DuckDB stores the reproducible warehouse; the public dashboard reads aggregate reports only.

  • Unique event IDs; valid event names; no orphan sessions or subjects crossing experimental arms.
  • First exposure selected using ROW_NUMBER; daily changes use LAG; left joins retain non-converters.
  • Immature windows excluded; schema and temporal integrity tested; DuckDB counts cross-checked against the independent SQLite implementation.
  • Exact binomial sample-ratio mismatch test, two-sided seeded permutation test and Newcombe confidence interval for the rate difference.
